## 现场可做的三个动作

| 动作 | 预期现象 | 说明什么 |
|---|---|---|
| 点线索表任意一行 | 右侧出现证据集：发票及支付记录 + 合同台账记录 | 每条线索都能回到源记录 |
| 把「相对门槛」拖到 0 | `CG-202606` 出现在「新增」列表 | 差 300 万但仅占 3.61%，原本被相对门槛挡住 |
| 把「绝对门槛」拖到 5 万 | 低档线索成批消失 | 阈值影响的是工作量，不是模型对错 |

## 常见问题

**Q1：`python3: command not found`**
试 `python`；Windows 上一般用 `python` 而非 `python3`。

**Q2：报错 `ModuleNotFoundError: No module named 'openpyxl'`**
只在生成 Excel 总表时需要。脚本已做容错，会打印 `[SKIP] 未安装 openpyxl` 并继续，其余输出不受影响。
需要总表时执行 `python3 -m pip install openpyxl`。

**Q3：中文文件名乱码或路径找不到**
请在项目根目录执行，且目录名保持原样；路径含空格时用引号包住。

**Q4：报告打不开**
直接双击 `report/任务报告.html`；仍不行就改看 `out/输出总表.xlsx` 第一张子表。

**Q5：想从干净状态重跑**
```bash
rm -rf out/* data/raw/*
```
再按 STEP 1 开始。脚本不依赖历史产物。

## 讲的时候记住三句边界

1. **R1 看不到「应付」**——应付已确认而票、款都未发生时差额为 0，本模型不报，那属于应付挂账。
2. **红冲口径待确认**——11 表累计发票金额是否已剔除红冲，规范未明确；若含红冲，B2 虚高会产生「多开票」误报。
3. **阈值是演示值**——1 万元 + 5% 来自内控经验，须用 POC 核查结论回标。
